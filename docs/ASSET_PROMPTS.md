# 建议补图提示词

本轮仅整理提示词，没有调用生图，也没有修改原图。

## 1. 独立召唤小老鼠（已补齐，提示词留档）

参考图：上传项目中的 `初级奶鼠.png`；可附 `二级奶鼠.png` 作材质参考。

```text
为网页塔防游戏《保卫奶蛙》绘制一只独立的“召唤小老鼠”，它是参考图中奶鼠炮塔召唤出来的小型作战单位。严格沿用参考图的奶黄色身体、奶油白肚皮、圆润大耳朵、绿色大眼睛与软胶玩偶材质，角色要一眼看出属于同一套美术。它应比参考中的奶鼠塔更加幼小、低矮、轮廓简洁，采用四足向右小跑、轻微侧向的3/4俯视视角，头稍大，耳朵和细长弯尾完整可见，表情勇敢可爱。低饱和奶油色系，左上柔光，细节适度，缩小到32至48像素仍能辨认。只画一只小老鼠，不画召唤师，不戴皇冠、帽子、背包或披风，不拿奶酪，不带法阵、攻击光效或背景。四肢结构自然完整。主体居中，身体与尾巴四周留足至少10%的透明安全边距。输出1024×1024 PNG，真实透明Alpha背景；不要画灰白棋盘格、地面、文字或水印。
```

## 2. 重伤奶蛙之心（建议替换1张）

参考图：上传 `初始奶蛙之心.png` 和 `受伤奶蛙之心.png`，以初始图为形状与定位依据。现有重伤图仅用于说明需移除的红色滴落，不作为风格主参考。

```text
为网页塔防游戏《保卫奶蛙》制作“奶蛙之心·危险状态”的独立贴图。请严格以所附正常状态与受伤状态为同一角色参考，保留奶黄色半透明软胶心形主体、绿色圆眼睛、脸型、身体比例、镜头、柔和左上光照。心形主体的中心位置、宽高和底部位置与正常状态对齐，仅将表情改为慌张担忧：眉毛上扬、嘴微张、眼角少量透明泪滴，主体亮度略降，在表面增加两三条浅金色柔和细裂纹。整体仍然温暖软萌，不能出现红色裂纹、红色液体、血液、滴落、熔岩、真实器官或尖锐碎片。不要将心画碎成两半，不增加祭坛或背景。保留柔和轮廓与清晰五官，适合缩小显示。单个角色居中，留足透明边距，输出1024×1024 PNG，真实透明Alpha背景；不要棋盘格、文字、水印。用于与其他生命状态切换，主体大小和锚点必须保持连续。
```
