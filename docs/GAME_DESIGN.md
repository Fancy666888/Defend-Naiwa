# 首版实现规则

## v0.2 难度与声音更新

- 默认进阶挑战，十波与134只数量不变，初始奶量、塔价与基础攻击保持不变。每波血量倍率为1.15/1.3/1.8/2.4/3.2/4.2/5.4/6.8/8.2/10；普通怪速度从1倍增到1.64倍，出怪间隔从1.05秒降至0.48秒。
- Boss采用独立配置：9800生命、33.75像素/秒；避免直接套用普通怪10倍曲线使所有阵容都难以击杀。
- 点击开始默认启用音乐与音效；音乐循环15.36秒，16种单次效果。暂停、帮助、后台与结算时停止背景音乐，胜负音效仍播放；静音停止所有声音，重开不叠加音乐。
- 使用独立挑战纪录键 `naiwa-best-v2`，旧纪录保留；音频偏好键为 `naiwa-audio-v2`。

- 初始360奶量、12生命，建造/升级价格、大部分敌人及经济规则沿用附带方案。波间准备8秒、生成间隔1.2秒；十波134只，清波奖励40+5n。
- 大笑伤害27/48/82、射程170/185/205、冷却1.45/1.25/1.05秒；目标附近72/84/100范围伤害，眩晕0.38/0.48/0.58秒，同目标再次眩晕需间隔4秒。
- 奶狗伤害35/62/106、射程185/205/225、冷却1.25/1.1/0.95秒；70°扇形，普通敌人沿路径回退14/18/22像素，Boss回退5像素。
- 功夫伤害60/106/180、射程125/140/155、冷却0.9/0.78/0.66秒；每个炮塔对每个目标分别记录连击，第三下双倍伤害。
- 奶鼠伤害17/24/34、小鼠攻击间隔0.6秒、索敌半径235/255/280加40容差；召唤冷却3/2.8/2.5秒，同塔上限1/3/5，存在6秒，追击速度180像素/秒；出售立刻清除所属召唤物。升级后新召唤物按新等级，已有小鼠保留生成时等级直到自然到期。
- 每次击杀能量+4，敌人漏过能量+6，上限100；主动技全场60伤害、减速40%持续2秒。
- 12生命三星、6–11两星、1–5一星；最高星级存本地，当前对局不持久化。

## 首版美术取舍

四类炮塔12张、四种敌人、独立小鼠、心的正常/受伤/破碎、入口祭坛荷叶、地图装饰、奶瓶能量心LOGO已接入运行素材。全部保留原件，用副本缩放导出。透明边缘可能仍有轻微杂色，未宣称已完成逐像素精修。

道路用代码绘制并与逻辑坐标一致；重伤阶段用受伤图+闪烁；奶潮与各攻击效果用程序图形。无逐帧动作、正式背景音乐、多关、关卡选择或账号系统。布局包含手机媒体查询与横屏建议，未在真实手机上验收。
