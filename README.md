# 保卫奶蛙 · 奶香荷塘

使用现有角色素材制作的一关网页塔防挑战版（v0.2）。Vite + TypeScript + Phaser 3，固定路线，四种三级炮塔，十波敌人、134只捣蛋鬼。

## 本地运行

建议 Node.js 22.18+ 或 Node.js 24+。依赖已安装在当前项目中；复制到其他电脑后先执行 `npm install`。

```sh
npm run dev
```

打开终端显示的地址，通常是 http://127.0.0.1:5173 。需通过本地服务器运行，不能双击HTML直接玩。

```sh
npm test
npm run build
npm run preview
```

`dist/` 是正式构建产物，可以由静态HTTP服务器提供。当前没有部署到公网，也没有任何在线账号或数据服务。

## 操作

1. 点击「开始守护」，选择右侧伙伴，再点击空荷叶建造；8秒后第一波自动开始，也可提前开始。
2. 点击已有炮塔，在右侧升级或出售。每类可升至三级，出售返还累计费用的60%。
3. 金边荷叶缩短15%攻击/召唤冷却。大笑范围眩晕、奶狗扇形击退、功夫近战连击、奶鼠召唤1/3/5只小鼠。
4. 能量满100后释放奶潮守护：全场60伤害，减速40%持续2秒。
5. 暂停、1×/2×、重新开始按钮在地图周围。快捷键：1–4选伙伴、P暂停、空格技能；焦点在按钮上时空格按浏览器惯例激活该按钮。
6. 手机布局自适应，推荐横屏；下方「键盘 / 触控建造辅助」提供可聚焦的荷叶按钮。

点击「开始守护」后默认播放原创荷塘循环音乐和16种战斗/界面音效。右上「声音开 / 声音关」切换音乐与音效；浏览器必须先收到点击才能播放音频。暂停与切后台停止音乐，继续时恢复；攻击音有限频和压限，避免大量小鼠同时攻击时叠加过响。

从第三波起逐步提高敌人血量、移动速度和出场密度，末波普通怪血量为基础10倍、Boss为9800血量。前版最高纪录保留在旧存储键中，挑战版单独记录星级。

## 存储与范围

仅将最高星级、音效偏好保存到当前浏览器的 localStorage；刷新会重新开始本局。浏览器禁用存储时游戏仍可运行。模拟验证：混合七塔可三星通关，纯大笑七塔剩6生命，四塔满级停建会在第十波失败；尚未进行真人手感平衡。

## 文件

- `src/config.ts`：地图、建塔位置、炮塔与敌人数值、十波组合。
- `src/engine.ts`：与渲染独立的模拟、经济、攻击、召唤与胜负逻辑。
- `src/scene.ts`：Phaser地图、角色、射程、特效与程序动画。
- `src/main.ts`、`src/style.css`：界面、输入和存储。
- `src/audio.ts`、`public/audio/`：用户点击解锁、背景音乐循环、音效事件、暂停静音与限频。
- `scripts/prepare_audio.py`：用 NumPy 生成原创音乐与音效，不依赖外部音频资源。
- `npm run check:audio`：构建后核对17个音频的格式、非静音波形、峰值和发布副本。
- `src/assets.json`：运行贴图与源文件对应关系。
- `public/assets/`：运行用副本，全部源图仍在项目根目录。
- `scripts/prepare_assets.py`：使用 Pillow 缩放导出、按人工确认区域拆分地图装饰；重跑需要安装 Pillow，不是启动游戏的必需步骤。
- `scripts/balance.ts`：三种策略的合法经济模拟，执行 `node --experimental-strip-types scripts/balance.ts`。
- `scripts/verify-assets.mjs`：构建后执行 `node scripts/verify-assets.mjs`，核对运行图与发布图。
- `docs/TEST_REPORT.md`：实际验证结果与未测项目。

现有道路合图未作为寻路或碰撞依据；道路与攻击特效由程序绘制。重伤心暂使用受伤贴图配合闪烁。角色使用单帧位移、弹跳与缩放动画，不是逐帧行走动画。原始UI卡片的棋盘格没有带入游戏。
